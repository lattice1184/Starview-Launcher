# Starview v1.0.9

## 修复

- **大文件下载「假成功」根治**：此前下载大文件时可能提示「下载完成」但目标文件根本没落地——分片合并阶段的误判会导致报成功、实际文件丢失。已修复（仅当完整文件真正落盘才报完成）
- 下载历史「位置」按钮支持目录：模组 / 整合包安装记录不再提示「文件已不存在」，直接打开对应文件夹
- 首次设置游戏目录后，主页版本列表立即刷新，不用再切页 / 重启
- 更换游戏目录后，版本浏览页自动跟随新目录，删除文件秒同步
