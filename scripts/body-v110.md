# Starview v1.1.0

## 自动修复更透明

- **启动失败原因正大光明贴出来**：自动修复失败时弹崩溃窗展示真实原因（不再只有红字 + 一闪而过的提示），可一键修复
- 自动修复读取**当时启动日志**执行诊断下载，不再只靠内存控制台
- 0 字节 / 损坏的客户端 jar 不再被「文件已完整」跳过

## 版本与实例

- **加载器覆盖原版**：装 Fabric / Forge 后，同版本已装原版自动隐藏合并（加载器成唯一条目）；删加载器时连带清理被吸收的原版，删得干净
- **主页自动选中最新安装的版本**：下载模组「跟随实例」不再落错实例

## 安装交互（PCL 式）

- 点「安装」**直接弹系统目录选择器**，默认指向对应实例的 mods 文件夹，取消即不装；不再两步（先选实例下拉、再填路径）
- 「匹配文件」下载同样强制选目标，未选实例会拦截提示（不再静默落进 downloads 缓存）
- 整合包豁免：装独立实例 downloads/modpacks，不弹目录选择器
- 修复模组装进错误目录的嵌套路径（TACZ 落错版本的问题根治）

---

- 内置 CurseForge API Key（构建期加密注入），CF 搜索 / 下载开箱即用；也可在设置里填自己的 Key
- 两个版本任选：**望星.exe**（自包含，双击即用，约 84MB） / **望星-轻量版.exe**（需 .NET 10 Desktop Runtime，约 48MB）
